# Control and reach outrank autonomy for users

Users of competing computer-use products keep asking for three things they cannot find: multi-step work they can trust without checking it again, a clean hand-off at the login, 2FA or CAPTCHA wall after which the agent picks the task back up, and reach beyond one operating system or surface, where requests for Linux desktop apps drew **1,464 and 655 reactions** on the Codex and Claude trackers. Developers add cheap, deterministic repeat runs, and enterprise buyers add a per-agent identity, least-agency tiers, replayable evidence and a contained desktop, controls that fewer than half of CISOs say they have today. What users praise is control and continuity rather than raw autonomy: the agent works in their own signed-in session, they can watch it and take over, and since April 2026 it can work in the background without taking the cursor, while developers reward accessibility-tree targeting because it is precise and cheap in tokens. Against 42 features drawn from that evidence, computer-use-mcp is **ahead on 7, at parity on 4, partial on 22, missing on 4 and not applicable on 5**. It leads where a local server has leverage: coverage of three operating systems in any MCP host, a status card with Pause, Stop and take-over that never appears in captures, on-device OCR for apps that draw their own UI, honest results for every action, both MCP protocol generations and independence from any one model. Its partial ratings fall on the features users love most, because background input works only on macOS and stops short of drags, take-over resumes but the agent cannot ask the person to step in, the accessibility tools are missing from the default profile, Windows has never run on a real multi-monitor desktop, and text read off the screen is not labelled untrusted. It has no record-and-replay, no evidence bundles and no agent identity in its audit log, although its docs promise one. Most of the lead sits on a merged but untagged 7.7.0, so the first recommendation is to ship it; the next three, a hand-off tool, untrusted labels on screen text and better diagnosis of stale permissions, are small and answer the strongest evidence.

*Method and conventions.* This report draws on five research notes in [`2026-10-25-computer-use-gaps-inputs/`](2026-10-25-computer-use-gaps-inputs/) (complaints about hosted agents, gaps in open-source tools, loved features, enterprise expectations, and an inventory of computer-use-mcp) and builds on the [2026-10-23 competitor study](2026-10-23-competitor-study.md) and the [2026-10-25 live-share review](2026-10-25-live-screen-share.md). Code paths point at `feat/live-share` at `9ded54f`; files that branch does not change are identical on `main` at `6bca225`. Status tags read as follows: **[main]** is merged on main as 7.7.0, which is untagged; **[PR]** exists only on the open `feat/live-share` or `fix/helper-identity` branch; **[branch]** is the unmerged `fix/run-console-current-frame`; **[planned]** is a todo in a spec or in STRATEGY; **[proposed]** appears only in an uncommitted review; and **[none]** means nothing was found. "This pass" marks a claim re-checked here by grep or by reading the file, and every other code claim relies on the inventory's file:line citations. The evidence has limits: Reddit blocked the crawler, star growth was read off charts and is accurate to about ±5%, several 2026 review sites are affiliate content and are marked where used, no independent benchmark compares desktop MCP servers, and no user-written comparison names computer-use-mcp.

## Reliability, the login wall and reach top every complaint list

**Every hosted product draws the same core complaints.** Multi-step work is unreliable: the agent loops, clicks the wrong thing, stalls on a modal or declares success too early. It is also slow, often slower than doing the task by hand. In The Verge's test, Atlas took about ten minutes to add three items to an Amazon cart, against about two for Comet ([Futurism](https://futurism.com/artificial-intelligence/openai-atlas-web-browser-messy)). In a public benchmark, a screenshot-driven agent spent about 17 minutes and 500K tokens on a task that took about 20 seconds through the app's API ([The Register](https://www.theregister.com/ai-and-ml/2026/05/07/ai-vision-agents-use-45x-more-tokens-than-apis-in-benchmark/5231346)).

Security fear produces the most engagement. Three threads stand out on Hacker News: Cowork exfiltrating files (**870 points**, [HN 46622328](https://news.ycombinator.com/item?id=46622328)), the Claude for Chrome launch (799, [HN 45030760](https://news.ycombinator.com/item?id=45030760)) and Gemini 2.5 Computer Use (636, [HN 45507936](https://news.ycombinator.com/item?id=45507936)).

Billing anger concentrates where users pay for failed attempts. Manus and Genspark sit near 1.2–1.9 out of 5 on Trustpilot, mostly over credits burned on failed tasks ([Trustpilot: Manus](https://www.trustpilot.com/review/manus.im); [Trustpilot: Genspark](https://www.trustpilot.com/review/genspark.ai?page=7)). A Cowork Pro subscriber reported hitting the usage cap after about ten minutes ([comments](https://ruben.substack.com/p/claude-computer/comments)).

Logins stop agents cold. Chrome's auto browse paused at MFA. It also cancelled the wrong subscription tier despite a stop rule, which took customer service to reverse. Its reviewer concluded that agents which cannot survive a 2FA wall are toys ([Sean Kim](https://blog.imseankim.com/chrome-auto-browse-gemini-agentic-hotel-form-fill-google-io-2026/)).

**The complaints divide by architecture, and in 2026 the market moved toward the half a local server owns.** Agents that run in a cloud VM draw complaints about logins, CAPTCHAs and a virtual shopping cart that never reaches the real one. In The Verge's Etsy test, the agent said it had added items that never appeared ([ninetwothree, secondary](https://www.ninetwothree.co/blog/chatgpt-agent-mode)).

Agents that run on the person's machine draw a different set: OS permission plumbing, a machine that must stay awake, no sandbox, fights over the screen, and prompt injection with real credentials within reach. Vendors moved from the first group to the second this year. Claude's computer use reached beta on macOS and Windows ([Claude help](https://support.claude.com/en/articles/14128542-let-claude-use-your-computer-in-cowork)). ChatGPT Work, which replaced ChatGPT agent, operates the person's own desktop ([TNW](https://thenextweb.com/news/openai-chatgpt-work-agent-launch)).

The churn behind that move is itself a complaint. OpenAI and Google retired Operator (folded into ChatGPT agent), ChatGPT agent (removed in August 2026), Atlas (shut down on Aug 9, 2026) and Mariner (shut down on May 4, 2026) without a migration path, so users who had built scheduled workflows migrated twice in about thirteen months ([OpenAI community](https://community.openai.com/t/agent-mode-was-removed-with-no-real-replacement/1389601); [Wikipedia](https://en.wikipedia.org/wiki/ChatGPT_Atlas); [GIGAZINE](https://gigazine.net/gsc_news/en/20260507-google-shuts-down-project-mariner/)). ChatGPT agent reportedly fell from about 4M weekly paying users to under 1M ([The Decoder](https://the-decoder.com/chatgpt-agent-reportedly-lost-75-of-its-users-because-nobody-knew-what-it-was-actually-for/)). Meanwhile Codex and ChatGPT Work passed 10M weekly users ([TNW](https://thenextweb.com/news/openai-agents-10-million-chatgpt-work)). Computer use keeps its users when it serves as the fallback inside a workflow people already have. That is exactly where an MCP server sits.

**In developer trackers, the most-reacted requests are about where computer use runs at all.** Codex's Linux desktop app drew **1,464 reactions** ([#11023](https://github.com/openai/codex/issues/11023)). Claude Desktop for Linux drew 655 ([#65697](https://github.com/anthropics/claude-code/issues/65697)) and OpenClaw's Linux and Windows request drew 95 ([#75](https://github.com/openclaw/openclaw/issues/75)). Next come computer use from the Codex CLI (43, [#20851](https://github.com/openai/codex/issues/20851)) and attaching to the Chrome session the person already has open (61, [#140](https://github.com/ChromeDevTools/chrome-devtools-mcp/issues/140)).

On the desktop MCP servers themselves, reactions are near zero, and the demand shows up instead as long threads about reliability: settle delays ([cua #3971](https://github.com/trycua/cua/issues/3971)), cancelling a call in flight ([#3796](https://github.com/trycua/cua/issues/3796)), a ScreenCaptureKit lease held by one process that makes a second server exit ([Peekaboo #1145](https://github.com/openclaw/Peekaboo/issues/1145)) and accessibility polling that freezes Chrome ([MacOS-MCP #5](https://github.com/CursorTouch/MacOS-MCP/issues/5)). By volume, Windows is the largest bug class by far: **48% of Codex's 931 computer-use issue titles mention Windows** ([search](https://github.com/openai/codex/issues?q=is%3Aissue+%22computer+use%22+in%3Atitle)). The top ones are a Windows 10 capture failure with 89 comments ([#25178](https://github.com/openai/codex/issues/25178)) and a frame deadlock ([#35446](https://github.com/openai/codex/issues/35446)).

macOS permission breakage clusters around OS updates. It accounts for 9.7% of Claude Code's computer-use titles ([search](https://github.com/anthropics/claude-code/issues?q=is%3Aissue+%22computer+use%22+in%3Atitle)). Codex's "every request denied despite the grants" issue stayed open from April to October ([#18896](https://github.com/openai/codex/issues/18896)).

False success is now an issue class of its own. Examples are known-answer regressions in browser-use ([#6031](https://github.com/browser-use/browser-use/issues/6031)) and Stagehand clicks that return without committing ([#2486](https://github.com/browserbase/stagehand/issues/2486)).

**Six missing features recur across trackers, and each has at most one project claiming to ship it.** Users want background operation that does not take over the machine ([claude-code #87115](https://github.com/anthropics/claude-code/issues/87115)), several agents sharing one desktop or browser (Chrome DevTools MCP multi-session, 24 reactions, [#926](https://github.com/ChromeDevTools/chrome-devtools-mcp/issues/926)), and pause and hand-off inside a run (browser-use human-in-the-loop, 18 reactions, [#221](https://github.com/browser-use/browser-use/issues/221)). They want honest evidence for each action ([#5137](https://github.com/browser-use/browser-use/issues/5137)), and remote or VM execution: a remote agent with local tools drew 44 reactions ([Hermes #18715](https://github.com/NousResearch/hermes-agent/issues/18715)), and a Mac-sandboxing post drew 823 points ([Agent Safehouse](https://news.ycombinator.com/item?id=47301085)). The sixth is record once, replay deterministically. The Gemini thread suggested exploring once and then generating a Playwright script ([HN 45507936](https://news.ycombinator.com/item?id=45507936)), and launches built on the idea drew attention: Understudy 120 points ([HN](https://news.ycombinator.com/item?id=47353957)), Muscle-Mem 226 ([HN](https://news.ycombinator.com/item?id=43988381)) and Libretto 134 ([HN](https://news.ycombinator.com/item?id=47780971)). Token cost runs underneath all of these. "Computer Use is 45x more expensive than structured APIs" reached **495 points** ([HN 48024859](https://news.ycombinator.com/item?id=48024859)). Developers switch tools on context cost, from Playwright MCP to a Playwright skill (189 points, [HN](https://news.ycombinator.com/item?id=45642911)) or to leaner browser MCPs.

Two things are conspicuously not asked for. No tracker searched contained a request for undo, yet the harm reports show what its absence costs: 1,000 promotional emails deleted by Cowork on request ([aireiter, citing WIRED](https://aireiter.com/blog/claude-cowork-computer-use-review)), a purchase on a fake Walmart site ([HackMag on Guardio](https://hackmag.com/news/scamlexity)) and the wrong subscription tier cancelled ([Sean Kim](https://blog.imseankim.com/chrome-auto-browse-gemini-agentic-hotel-form-fill-google-io-2026/)). Demand for scheduling and voice also rests on single issues with no reactions.

**The benchmark record shows which of these failures a server can fix.** On short desktop tasks, leaders now beat the OSWorld-Verified human baseline of 72.36%, at up to 90.19% ([Presenc](https://presenc.ai/research/osworld-computer-use-leaderboard-2026)). Long workflows remain far from solved. On OSWorld 2.0, binary completion was 20.6% at release and is 44–49% at best now ([arXiv 2606.29537](https://arxiv.org/abs/2606.29537); [Presenc](https://presenc.ai/research/osworld-computer-use-leaderboard-2026)).

Failure analyses agree that most failures are decisions, not clicks. Planning and perception account for **57.3%** of root causes in one 619-failure study ([arXiv 2610.27645](https://arxiv.org/html/2610.27645v1)). Grounding, state and tool errors account for only 13.9% of failures in an audit of 150 trajectories ([arXiv 2607.28367](https://arxiv.org/html/2607.28367v1)).

A server cannot make a model plan better. It can do three things: make verification cheap, make handing control back easy, and remove model turns. Those three tests drive the matrix below.

## People praise control and continuity, not autonomy

**The two most-praised features are about trust: working in the person's own session, and letting the person take the wheel.** browser-harness lets Claude Code, Codex or Cursor drive the person's real, logged-in Chrome. It reached **18,609 stars in six months** ([GitHub](https://github.com/browser-use/browser-harness)). Auto browse pulled tax documents from Gusto and ADP without re-authenticating ([Sean Kim](https://blog.imseankim.com/chrome-auto-browse-gemini-agentic-hotel-form-fill-google-io-2026/)).

People describe watching an agent work as the moment it clicked for them. One Comet user said it "felt like magic watching it work" ([HN](https://news.ycombinator.com/item?id=45658810)). Being able to correct a run is the negative proof: a reviewer marked down Opera Neon because its agent added a funeral wreath to a flower order and ignored the reviewer's clicks ([Remio](https://www.remio.ai/post/opera-neon-review-the-confusing-future-of-ai-browsers)).

Stopping at the irreversible step is praised when it is right and attacked when it is overdone. Sean Kim credited auto browse for stopping at checkout and at Send ([post](https://blog.imseankim.com/chrome-auto-browse-gemini-agentic-hotel-form-fill-google-io-2026/)). Codex CLI users complain about confirmations even for allowlisted commands ([#7740](https://github.com/openai/codex/discussions/7740)).

**Background operation became the headline desktop feature in April 2026.** Federico Viticci called Codex's computer use the best he has tested. It drives several Mac apps at once with parallel virtual cursors that never bring apps to the front. He attributed its precision to reading each app's accessibility tree, and called its permission onboarding the best he had seen in a third-party Mac app ([MacStories](https://www.macstories.net/notes/openais-new-codex-app-has-the-best-computer-use-feature-ive-ever-tested/)). cua-driver's "drive any macOS app in the background without stealing the cursor" drew **192 points**, and a commenter who called it incredible asked for Windows ([HN](https://news.ycombinator.com/item?id=47936312)).

**Developers reward precision and token thrift above everything else, and the money follows browser tools.** agent-browser returns only interactive elements, as refs. One write-up puts its snapshots at about 1,000 tokens against about 13,700 for Playwright MCP, a comparison its critics call unfair ([paddo.dev](https://paddo.dev/blog/agent-browser-context-efficiency/)). Peekaboo's author argues that most agents struggle with more than about 40 tools ([steipete.me](https://steipete.me/posts/2025/peekaboo-mcp-lightning-fast-macos-screenshots-for-ai-agents)).

Downloads show how small the desktop category still is: @playwright/mcp drew **29.3M npm downloads in September 2026**, up 5.9x since January ([npm API](https://api.npmjs.org/downloads/point/2026-09-01:2026-09-30/@playwright/mcp)), against about 39.5k a month for windows-mcp on PyPI ([pypistats](https://pypistats.org/packages/windows-mcp)) and 3,790 in the last 30 days for @zavora-ai/computer-use-mcp. Among desktop projects, growth concentrates in cua (about 11k to 31k stars this year), which ships background drivers, coverage of every OS and a VM story ([GitHub](https://github.com/trycua/cua)).

**The "aha" moments are tedious chores, apps with no API, and learning software.** Users say they saved time on multi-site chores in their own browser, such as carts and scarce items, contact forms and documents pulled from portals. Codex playing music, summarising Slack and testing Shortcuts in the background impressed Viticci ([MacStories](https://www.macstories.net/notes/openais-new-codex-app-has-the-best-computer-use-feature-ive-ever-tested/)). For creative apps, the aha is guidance, not autonomy. Clicky is a Mac helper beside the cursor that talks and points at the right button. Its launch demo drew about 2.9M views, and people used it to learn Blender and DaVinci Resolve ([X](https://x.com/FarzaTV/status/2041314633978659092)). XDA called it the most useful thing it had tried that year ([XDA](https://www.xda-developers.com/someone-built-tiny-ai-that-lives-next-to-your-cursor-the-most-useful-thing-ive-tried-this-year/)). For developers, the aha is an agent that tests the UI it just built ([HN](https://news.ycombinator.com/item?id=47500276)), and they adopt video-and-screenshot proof bundles such as ProofShot ([HN](https://news.ycombinator.com/item?id=47570335)).

Scheduling, recorded workflows, memory and voice get heavy vendor investment but little genuine praise from users. One user switched screenpipe off because always-on recording overheated an M1 MacBook ([HN](https://news.ycombinator.com/item?id=49031269)), and Comet's voice mode loops ([MakeUseOf](https://www.makeuseof.com/perplexity-comet-review-after-7-months/)). One Dispatch tester praised the opposite instinct from screen-first agents. Claude tried connectors first and used the screen as a last resort ([AI Blew My Mind](https://aiblewmymind.substack.com/p/claude-computer-use-guide-6-workflows-tested)).

## Buyers want identity, containment and replay; fewer than half have them

**Analysts treat the category as "block until proven".** Gartner told CISOs in December 2025 to block AI browsers for now ([The Register](https://www.theregister.com/2025/12/08/gartner_recommends_ai_browser_ban/)). Okta's 2026 survey of 306 security executives shows how few have the basics: **47%** can identify every AI agent in their environment, 46% can centrally control what agents access, 45% can authorise individual agent actions, and only **26%** can revoke agent access within minutes ([Okta](https://www.okta.com/newsroom/articles/global-ciso-insights-2026/)). Forrester's AEGIS framework rests on "least agency" and treats each agent as an identity with an owner and a lifecycle ([Forrester](https://forrester.com/technology/aegis-framework)). Anthropic still keeps desktop computer use off its Team and Enterprise plans ([Claude Code docs](https://code.claude.com/docs/en/computer-use.md)). In order of frequency, these sources demand an inventory of agents with an identity per agent, per-app tiers, per-action approval, revocation within minutes, audit tied to that identity (increasingly with a screenshot trail), a contained desktop, and data-loss prevention over what reaches the model.

**The security record says screen content is an attack surface, and no vendor offers a deterministic defence.** Brave showed instructions hidden in images, invisible to people, being read out of screenshots and followed ([Brave](https://brave.com/blog/unseeable-prompt-injections/)). A hidden-text document made Cowork upload a user's files to an attacker's account ([PromptArmor](https://www.promptarmor.com/resources/claude-cowork-exfiltrates-files)). A calendar invite steered Comet into a 1Password vault ([Zenity](https://www.businesswire.com/news/home/20260303909038/en/Zenity-Labs-Discloses-PleaseFix-Vulnerability-Family-in-Perplexity-Comet-and-Other-Agentic-Browsers)).

Vendors answered with layers, each probabilistic. Anthropic runs classifiers and claims under 0.08% attack success in Chrome on internal tests ([Anthropic](https://support.claude.com/en/articles/12902428-use-claude-in-chrome-safely)). Google added a User Alignment Critic that sees only action metadata, plus origin sets ([9to5Google](https://9to5google.com/2025/12/08/gemini-chrome-agentic-security/)). Claude's desktop computer use sets category tiers: browsers and trading apps are view-only, terminals and IDEs click-only, and everything else gets full control; the terminal is kept out of screenshots, and a consumed Esc stops the agent ([Claude Code docs](https://code.claude.com/docs/en/computer-use.md)). Simon Willison's "lethal trifecta" is the field's frame: private data, untrusted content and a way to send data out should never be combined ([post](https://simonwillison.net/2025/Jun/16/the-lethal-trifecta/)).

**Operating-system vendors are turning containment into a platform primitive that a plain npm package cannot use.** Windows gives agents separate accounts, an agent workspace with its own desktop, and signed agents that can be revoked ([Windows security book](https://learn.microsoft.com/en-us/windows/security/book/operating-system-agentic-security)). Its on-device MCP registry runs servers contained only if they are .exe binaries with MSIX package identity. `.mcpb` bundles and unpackaged apps cannot run contained ([Microsoft Learn](https://learn.microsoft.com/en-us/windows/ai/mcp/servers/mcp-containment)). Microsoft Execution Containers reached general availability on Oct 7, with session containers that isolate the desktop, clipboard and input ([Windows Developer Blog](https://blogs.windows.com/windowsdeveloper/2026/10/07/microsoft-execution-containers-policy-driven-containment-for-ai-agents/)).

Regulation points the same way. The EU AI Act's Article 12 requires automatic logging and Article 14 configurable human oversight. Article 26 makes deployers keep logs for at least six months ([Help Net Security](https://www.helpnetsecurity.com/2026/04/16/eu-ai-act-logging-requirements/)). OWASP's agentic list names the "attribution gap" left by agents without a governed identity ([OWASP](https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/)).

**The leads sit where a local server has native leverage, and several partials are self-inflicted.** The seven "ahead" rows cover reach across three operating systems, the lifecycle of the person's controls, OCR for self-drawn apps, protocol coverage, model independence, continuity and a fast local kill switch, and hosted products cannot easily match any of them. Screen text is not labelled the way web text already is, an audit identity variable is documented but never written, and Linux keep-awake is claimed but not implemented. Of the four missing rows, record-and-replay and per-agent identity carry the most user evidence. The other two, site memory and central policy management, carry less.

**The user evidence also re-orders the existing plans.** The v8 app bridges, approved in principle, route Unreal and Blender through their own MCP servers. They match the switching logic users state: take the cheapest reliable route first, and use the screen last. The 15-item gaming plan does not have the same backing. The loved-features research found little user evidence about automating games, beyond chess coaching through Clicky. Its key-fidelity items should therefore follow P0 and P1 rather than compete with them.

Voice (L2) has weak evidence as a way to control agents and strong evidence as part of a tutor. It belongs with guide mode, not with agent control. Four things should stay out of scope. Hosting a cloud browser or VM is another product. Solving CAPTCHAs is something every major vendor prohibits. Scheduling belongs to the host, and Claude Desktop already skips tools that need a person in scheduled runs ([changelog](https://claude.com/docs/cowork/changelog)). Always-on screen memory is something its own users switch off over heat and privacy.

## Conclusion

The 2026 move by vendors from cloud VMs onto the person's own machine changed which layer competes. The complaints that remain are the ones a local server owns: permission plumbing that breaks after updates, a machine that must stay awake, fights over the cursor, screen text that can carry instructions, and a person who needs to step in and hand back. computer-use-mcp already holds the hardest parts of that layer: reach across three OSes, a person-control lifecycle that rivals leak, OCR for self-drawn apps, and honest results. Its weakness is proof and defaults more than capability. A user installing it today probably gets 7.6.1 from npm. With the default profile, that user gets no accessibility tools, no published task numbers, Windows support never run on a real multi-monitor desktop, and an identity label the docs promise and the code never writes. With 86 stars ([GitHub](https://github.com/zavora-ai/computer-use-mcp)) and about 3,800 downloads a month, the project's leads are close to invisible. The cheapest gains come from shipping and from finishing decisions already made, ahead of any new subsystem.

The one new direction the evidence supports is replay. It is the only missing feature that serves both the loudest public complaint and the strictest buyers. A run compiled to a validated, deterministic step list attacks the 45x token cost directly, and it gives an auditor an artefact to read. The ingredients are already in the repository: a batch format that validates before it acts, a per-action effect contract, and an audit log. That gives computer-use-mcp a rare chance to be first rather than at parity, and to be first on every operating system in a category where rivals ship for one.
