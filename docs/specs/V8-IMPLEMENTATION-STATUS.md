# v8 implementation status

**Updated:** 2026-07-13

This record distinguishes implemented developer-preview behavior from roadmap
intent. It is deliberately not a claim that the later remote-control and
cross-platform certification milestones are complete.

## Implemented locally

- Frozen 64-tool v7 wire hash and compatibility tests; v8 remains additive and opt-in.
- Single definition registry and operation-aware action classification.
- Host-controlled dynamic tool profiles emit MCP tool-list changes and can only narrow or reshape the configured maximum authority. The dedicated `v8-safe` surface exposes only the governed v8 facade, rejects direct calls to disabled raw tools, and prevents `preview_action`/`execute_action` from reaching any tool outside the immutable host maximum.
- Enforced `shadow`, `background`, and `foreground` modes with no silent escalation.
- Capability query/preview/execute facade, typed interference, and operator-only background certification bound to an explicit ID, trusted adapter, live app version, exact low-level tool, instance-authority digest, fail-closed action predicate, expiry, and tamper-evident redacted trace. Operation labels cannot borrow authority. Reversible Finder/AppleScript and PowerShell sandbox reference adapters bind canonical realpaths and reject path/symlink and script-suffix escape. A shared exact-window AX/UIA semantic adapter rejects sensitive targets and proves mutation plus rollback by readback; its certified direct executor bypasses the focus-enforcing legacy handler while retaining the complete v8 policy/target/lease/receipt transaction. Durable restore revalidates app, contract, and instance bindings before registration.
- Expiring, idempotent target-intent reservations detect conflicting multi-agent plans before lease acquisition; reservations never grant mutation authority and are cancelled on pause, takeover, stop, or completion.
- One-writer fair leases, TTL/action/target boundaries, emergency stop, and OS input-clock revocation. A configurable physical-only global chord (default `Ctrl+Alt+Shift+Escape`) is detected on native macOS/Windows hook threads and latches native input off even if JavaScript is blocked or MCP is disconnected; native input loops stop between bounded effects and release agent-held inputs. API/PiP stop uses the same latch, and reset is authenticated-host-only. Revocation and TTL expiry abort an in-flight cancellable tool call; any effect that may already have crossed the mutation boundary becomes indeterminate and the lease is revoked.
- Native physical-user attribution replaces the combined idle-clock heuristic on macOS and Windows. macOS uses a passive HID event tap and hardware source-state filtering while runtime CGEvents use private sources; Windows uses dedicated low-level hooks and excludes `LLMHF_INJECTED`/`LLKHF_INJECTED` events. Governed physical input fails closed on those platforms when attribution is unavailable, and attributed backends never enter the old suppression window that could mask real takeover.
- Durable idempotency receipts with first-terminal-writer CAS; pending or corrupt reservation recovery is `indeterminate` and cannot auto-repeat effects. Legacy `{ isError: true }` handler results can no longer be committed as success: observation failures are rejected and mutation failures become indeterminate with lease revocation. File and directory state transitions are fsynced where the host filesystem permits it.
- Bounded capture → revalidate → execute → verify → conditional restore transactions.
- Typed, digest-bound UI-element, filesystem, registry, process, and window postconditions with independent Session readback. Exact UI value/form fields, filesystem write/append/delete and copy/move state transitions, named registry set/delete, and PID kill are automatically verified even when the handler reports success. Copy compares independently observed source/destination SHA-256 integrity: raw bytes for regular files and a path-independent canonical digest for directory entries, file bytes, and symlink targets. Explicit checks cover click outcomes and other targeted mutations. Expected values/content remain digest-only across supervisor events; a failed required check is indeterminate, revokes the lease, and is receipt-safe against replay.
- Policy-v2 resource/domain/process/app boundaries, provenance-bound approvals, secret redaction, safer v8 filesystem/scrape defaults, and fail-closed target evidence. Declared app/window arguments are bound into the resource digest and lease check even without a full evidence object; physical and semantic mutations require fresh evidence plus a live validator, and grants bind the active policy-config digest.
- Native sensitive-field classification for semantic `set_value`/`fill_form` inspects exact AX/UIA targets before preview, suppresses sensitive values before native serialization, recursively redacts accessibility results again in TypeScript, and exposes only allowlisted value-free signals. Missing/ambiguous facts fail closed; sensitive targets become `secret_access`; the assessment is action-digest-bound and revalidated immediately before mutation. Generic focused-field attribution for physical `type` remains outside this claim.
- Exact-action approvals remain one-use and bind the reviewed action/policy. Explicit session-operation grants are restricted to repeated non-sensitive `set_value`/`fill_form` edits with a digest-bound agent/execution group, app/PID/window, semantic selector set, operation, reversible class, mode, public/private labels, and trusted provenance. They contain no field labels or values, allow at most 20 uses/five minutes, and fail closed on any scope drift. PiP exposes a separate fixed 10-use/two-minute choice only for eligible previews. Pause, takeover, authorization loss, emergency stop, stop, completion, and deletion revoke issued and pending authority.
- Durable CAS sessions that recover paused, completion evidence, monotonic events, redacted integrity-chained journal, and exact-action supervisor approval. Journal restart verifies the complete chain, resumes each session sequence, and replays persisted history. Competing journal writers serialize through a cross-process lock and refresh before append/query; free-form pause and completion text is represented only by disclosure-safe metadata in supervisor events. Principal-bound deletion is restricted to terminal sessions and removes session records, receipts, grants, pending approval state, reservations, and the session's journal stream. Journal deletion atomically rebuilds and fsyncs a valid retained chain with a disclosure-safe retention marker. Explicit session-count and journal-byte limits fail closed until terminal data is pruned.
- Principal-bound `computer://session/current` and `computer://session/{sessionId}` resources expose lifecycle/completion state without routing through the legacy dispatcher. The template lists and completes only session IDs owned by the authenticated host.
- An opt-in experimental MCP Tasks adapter projects the authoritative v8 lifecycle into `working`, `input_required`, and terminal task states. MCP cancellation stops the v8 session and revokes any lease; the adapter cannot be enabled over the legacy dispatcher and does not replace v8 persistence or receipt semantics.
- A digest-bearing `computer://capabilities/manifest` reports the configured maximum and live active profiles, execution modes, persistence/task/supervisor feature flags, native input-monitor limitations, and every available actuator’s enforced modes and interference level without exposing configuration paths or secrets.
- Paginated `get_session_events` results are bound to a stable, packaged JSON Schema and digest exposed at `computer://audit/schema`. Durable journal queries retain each event's tamper-evident hash link instead of discarding chain metadata during reload/export.
- The optional `@zavora-ai/computer-use-remote` sidecar implements authenticated stateful MCP Streamable HTTP with 256-bit session IDs, bounded redelivery, per-authorization-context/principal isolation, explicit host-confirmed nonce-bound pairing, durable token-hash device state, rotation/revocation/expiry, rate limits, Host/Origin validation, loopback defaults, TLS-only explicit private-LAN binding, and a principal-filtered resumable event feed. Remote authorization loss, host lock, relay loss, or shutdown suspends owned v8 work and revokes control before further mutation.
- Remote steering uses `submit_follow_up`/`get_follow_ups`, a bounded monotonic memory-only instruction queue. Audit events retain only instruction digest/length metadata. Exact pending-action approval is exposed separately as `approve_action`, allowing `computer:approve` authority to remain distinct from observation, screenshots, session control, and execution.
- Authenticated local supervisor IPC protocol v2 and a sandboxed Electron PiP alpha with pause/resume/takeover/stop/emergency controls and opt-in visual review. The runtime captures only the already-authorized target app/window before mutation and after verification, stores validated PNG/JPEG frames in bounded process memory for five minutes, and emits metadata-only events. Pixels require both local principal authentication and prior session subscription; the main process strips session identity and unexpected fields before the renderer retains only the latest frame per phase. PiP loads no desktop native module and needs no capture permission. The PiP also shows the configured global chord, native latch generation, and latched mutation-blocked state; reset remains absent from MCP and requires explicit main-process confirmation.
- Resumable principal-bound onboarding for diagnostics, disclosure-safe OS permission guidance, capture, virtual pointer, semantic access, explicit emergency-stop education, and a least-privilege policy profile; raw screen, doctor summaries, and accessibility content are discarded rather than persisted. The configured chord/backend must be presented before acknowledgment, policy configuration is refused until acknowledgment, and unsupported physical-chord platforms are labeled API-stop-only. Revision CAS prevents concurrent host overwrite, and configuration returns the exact environment mapping with an explicit restart requirement.
- Packaged setup experiences now consume that protocol directly: `computer-use-onboard` supports interactive, non-interactive, and resume flows; separate pointer and emergency presentation/confirmation calls remove renderer races; a shared disclosure-safe view model, strict desktop controller, reusable WebView UI, Electron IPC/preload adapter, and Tauri invoke transport use versioned command/view schemas. Permission state persists only allowlisted IDs/statuses, while each renderer reconstructs bounded labels, remediation, and fixed macOS Settings URIs locally. A trusted desktop host can inject the settings opener and a host-only native macOS TCC prompt adapter for Accessibility and Screen Capture. Prompt and settings-navigation capability facts are separate; renderer commands contain only a known permission ID, Automation/arbitrary URLs/unsupported platforms fail closed, and no MCP tool can prompt or open OS settings. Native result details, principal/window IDs, paths, app IDs, environment values, pixels, arbitrary doctor text, and accessibility labels are excluded from renderer output; the non-secret chord/backend is visible, and the main host alone can read the resulting restart-required configuration.
- Model-authored subprocesses are both credential-scrubbed and cancellation-contained: POSIX launches use a dedicated process group and Windows invokes recursive `taskkill /T`, so caller cancellation, lease revocation, emergency stop, timeout, and output overflow terminate the interpreter plus ordinary descendants. A real parent/grandchild regression verifies containment while preserving the 8 MiB output cap. Deliberate POSIX daemon/session escape remains an explicit residual risk requiring stronger host sandboxing for untrusted code.
- Public deterministic fake-desktop harness plus a versioned, sanitized safety corpus covering commit/restore, target drift, post-effect crash, in-flight revocation, replay, and 10,000 seeded lease schedules.
- Public cross-platform reliability lab with a digest-bound 17-scenario matrix, versioned corpus/report schemas, operator-extensible probe runner, deterministic display/interference/emergency-latch guards, strict deterministic/integration/live evidence separation, validated raw counters, platform/approach/evidence-level metrics, and per-run integrity digests. The checked-in macOS baseline intentionally reports 3 deterministic passes, 16 unrun local cells, and zero live passes; the disconnected physical emergency-chord test, Windows UAC, RDP/session lifecycle, real mixed-DPI displays, macOS workspace modes, and X11/Wayland compositor rows remain explicit missing live evidence.
- Release-integrity API and schema bind native target identity, platform-package/root lockstep version, Mach-O/PE/ELF format, size, and SHA-256. CI now verifies all copied binaries and any already-published immutable version, fails closed before main publication, publishes the exact once-packed tarballs with npm provenance, generates CycloneDX SBOM and GitHub build/SBOM attestations, and installs the packed root on Node 18/20/22/current without optional packages. These controls do not claim external code signing or notarization.
- Evidence-driven release-readiness API/CLI with ten immutable gates and versioned signed-evidence/report schemas. Reproducible local reports remain self-attested; cross-platform CI, dual-platform live background, hardware interruption, ADK crash/resume, signing/notarization, and independent review require expiring Ed25519 statements from configured trusted keys bound to exact report/artifact digests. Structural verification rejects gate deletion, while signature verification rejects edited, expired, untrusted, and version-mismatched evidence. The published current report is correctly `no_go` with no achieved release stage.
- Public v8 conformance evaluator and packaged CLI combine scoped policy, multi-agent, and supervisor suite evidence with digest-valid live certification traces. Versioned JSON Schemas, source/output/report digests, adversarial tamper tests, exact platform/approach coverage, and per-platform CI artifacts prevent deterministic evidence from impersonating live proof. The current report marks `policy-v2` and `multi-agent-safe` passed, while `background-safe` and `supervisor-ready` remain partial until Windows evidence exists.
- Versioned TypeScript/Rust fixtures including multimodal evidence, actions, leases, receipts, events, completion, reservations, and terminal-session deletion.
- A public provider translation boundary normalizes equivalent OpenAI, Anthropic, Gemini legacy/streamlined function calls, and generic MCP actions into the same trusted `ActionRequest`; target/principal/viewport context comes only from the host, and parity tests prove identical action digests, classifications, and policy decisions. Gemini 1000×1000 coordinates are origin-aware and clamped to the trusted viewport, scroll pixel-to-step conversion must be explicit, browser/application bridge actions and inexact long-press semantics fail closed, and coordinate typing expands into separately identified and receipted actions. Packaged direct-SDK and LangGraph-compatible examples demonstrate complete preview/review/lease/execute/receipt lifecycles and checkpoint-before-interrupt recovery.
- A host-supplied browser bridge gives DOM/CDP-capable embeddings a non-physical path without bundling browser takeover. Its `browser_action` actuator is internal-only and absent from MCP discovery; the v8 facade binds fresh bridge/page/URL-digest/DOM/viewport evidence, domain policy, operation allowlisting, target revalidation, leases, receipts, and verified post-action evidence. Gemini navigation and optionally all pointer/keyboard actions route through it. Raw JavaScript evaluation is unsupported and model-visible evidence redacts the URL to a digest.
- The legacy batched `openai_computer` compatibility wrapper is rejected below the v8 runtime boundary, preventing one lease-budget unit from hiding multiple nested physical actions. Legacy batch/form loops now propagate cancellation and check it between individual mutations.
- Legacy `openai_computer` wire translation has been extracted from the session dispatcher into a pure, directly tested compatibility module while retaining the frozen v7 behavior.
- The v7 compatibility session has been reduced from the roadmap baseline of 3,141 lines to 434 lines. Cross-process lock/run-loop pumping, policy/audit, focus acquisition, target provenance, virtual pointer projection, diagnostics, filesystem/process/registry/notification/scrape, app/window, accessibility, Spaces, screenshot/zoom, physical input, scripting, and OpenAI compatibility execution now live in injected, directly tested modules. The remaining facade is orchestration: policy, locking, handler routing, error normalization, focus metadata, and audit wrapping.
- Progress notifications are drained before the terminal MCP tool result, preventing fast synchronous filesystem searches from racing transport close under parallel load.
- Safer-default migration is executable rather than documentation-only: v8

  receipts.

## Not yet release-complete

- Native injected-versus-physical attribution and the global chord are implemented for macOS and Windows, with local macOS synthetic-exclusion and latch/block/reset integration evidence. Linux now has best-effort X11 XI2 monitoring that excludes server XTEST devices but honestly reports `distinguishesInjected: false`; arbitrary virtual/uinput devices, native Wayland attribution, and a Linux physical global chord remain unsupported while API stop still latches mutation. A physical disconnected-client chord run, Windows live validation, physical-event p95 measurement, lifecycle fault injection, and the 10,000-race interactive hardware corpus remain platform-lab release work.
- Certified background adapters still need live Windows PowerShell/UIA traces, a live unlocked-workstation AX trace, and broader macOS/Windows app/version matrices. AppleScript, PowerShell, AX, and UIA reference workflows are implemented; one public live macOS Finder 26.2 trace is included. A live TextEdit AX attempt reached `loginwindow` and correctly failed closed when AX window resolution became unavailable.
- PiP visual-frame/evidence review is implemented with deterministic privacy and transaction coverage; it still needs signed cross-platform packaging and live macOS/Windows/Linux visual inspection before release sign-off.
- The deterministic fake-desktop corpus is implemented and should expand with new adapters and regressions; guided onboarding, disclosure-safe permission description, trusted-host macOS Settings opening, native macOS Accessibility/Screen Capture prompts, and dynamic tool-list negotiation are implemented. Windows/Linux have no equivalent audited prompt in this package and report `canRequestInProcess: false`; settings navigation is disclosed independently through `canOpenSettings`.
- A dedicated SQLite sidecar adapter remains optional future work. The shipped transactional embedded file store already provides cross-process CAS, atomic rename/fsync, bounded retention, recovery-paused semantics, and explicit terminal deletion/pruning; the MCP Tasks wire remains an optional lifecycle projection over that authoritative store.
- The authenticated Streamable HTTP sidecar, pairing, remote isolation tests, self-hosted relay adapter boundary, injected synchronous vault contract, and first-party macOS Keychain/Windows DPAPI/Linux Secret Service persistence are implemented as a developer preview. Vault paths commit hash-only device authorization before token issuance returns, reject Promise-returning adapters, and bind state to a monotonic digest/high-water anchor that detects partial rollback and recovers the one safe state-first crash window; atomic rollback of both same-vault records remains a documented platform residual. Atomic mode-`0600` storage remains the explicit headless fallback. A production relay deployment, signed cross-platform validation, and independent security review remain required before declaring remote control stable.
- Compositor-specific Wayland behavior remains unverified in interactive CI.
- The reliability lab is implemented as an evidence framework, not completed platform certification. Its live matrix still requires signed interactive/hardware runs for mixed displays, UAC, RDP, lock/sleep/wake, VM resize, macOS workspace modes, X11/Wayland, and interference injectors.
- The readiness evaluator deliberately reports `highestReadyStage: none`: the roadmap's minimum developer preview itself requires both macOS and Windows certified background workflows plus trusted ADK crash/resume evidence. This status can change only when valid external evidence is supplied, not through a configuration waiver.

The remote package never exposes the legacy dispatcher, never starts on import,
and requires an explicit principal-bound `v8-safe` host adapter.
